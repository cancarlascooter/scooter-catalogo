# Publicación aprobada: ropa y accesorios
El usuario autorizó crear un respaldo nuevo en GitHub y publicar los seis cambios revisados para su catálogo actual de ropa y accesorios.
- Conservar la configuración de producción, dominio, base de datos, imágenes, cuentas, marca y respaldo diario.
- No cargar datos, credenciales ni imágenes de la prueba independiente.
- Confirmar respaldo exitoso antes de migraciones remotas o despliegue.
- Probar localmente y comprobar permisos, inventario y datos conservados.
